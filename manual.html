從選歌，到唱完一輪

適用 Windows 的 Chrome／Edge。網頁放在 GitHub Pages；音訊取得、分離與評分在你的電腦進行。先完成一次安裝，之後從本機歌單載入就能再唱。

每次使用

已安裝？照這 6 步開始

  1. 執行工具資料夾的 start-local.ps1，用 Chrome 或 Edge 開啟主畫面。
  2. 按檢查本機工具，確認顯示已就緒。
  3. 按主畫面上方的歌曲庫，在本機歌單 · 點一首就載入裡點選歌曲；新歌先在歌曲網址貼上連結，再到聲曲分離與音高旋律擷取按準備歌曲基準。
  4. 戴耳機，開啟麥克風，確認說話時音量條有反應。
  5. 到評分設定，啟動，與成績選評分難度與評分範圍，再按從頭開始唱；成功啟動後，畫面自動捲到播放器，影片從 0 秒重新開始；分離音軌、錄音與後處理試聽會停止，避免重疊。
  6. 唱完按結束並結算。同一首再唱，直接按從頭開始唱。

主畫面頂端的配色可選「冷色調」或「暖色調」，冷色調使用深藍灰底與冰藍／青色重點，暖色調使用深咖啡底與琥珀色重點。預設為冷色調；此瀏覽器會記住你的選擇，切換時立即生效。下方「從頭開始唱／結束並結算」按鈕寬度為 2:1。主畫面上方有固定的區段導覽。按播放器、歌曲庫、收音、評分／結算可直接跳到該區；按操作手冊 ↗會開啟新分頁。切到手冊會停止收音，建議開始演唱前先閱讀。

「評分範圍」預設為只比已演唱範圍，後面尚未唱到的部分不扣分。要挑戰完整歌曲時，再自行切換為「整首歌曲」。

STEP 01 · 只需初次安裝

安裝並啟動本機工具

「先確認本機工具」整區可點標題收合；每次重新載入頁面時預設展開。收合不會停止本機服務，也不會變更歌曲庫設定。

  1. 安裝 Node.js 22 以上、Python 3.12、FFmpeg／ffprobe，並讓指令能從 PATH 執行。
  2. 從專案 GitHub下載程式碼，解壓縮到固定資料夾。之後在該資料夾開啟 PowerShell。
  3. 執行安裝指令。安裝會下載套件，需要網路與磁碟空間：
    powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-local.ps1
  4. 安裝完成後啟動：
    powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1
  5. 網站開啟後按檢查本機工具。若瀏覽器詢問本機網路存取，允許本站。

已有舊版工具，要使用主唱／和音分離：先執行 stop-local.ps1，更新工具程式碼後重跑安裝指令，再啟動。歌曲庫與模型不會因重跑安裝而移除。

重開機後需重新啟動工具；重灌 Windows 或換電腦則需重新安裝。此流程目前以 Windows 桌機為主，尚未完成 iPhone 的本機處理流程。

STEP 02 · 每台電腦各自設定

指定歌曲庫資料夾

  1. 在你的本機歌曲庫按選擇資料夾。
  2. 在 Windows 視窗選一個你要保存歌曲的資料夾，確認選取。也可輸入完整路徑，再按使用此位置。
  3. 確認網頁顯示設定成功；以後會記住這台電腦的選擇。

第一次一定要指定位置，別人的電腦不會沿用你的路徑。切換位置只改成讀取另一個歌曲庫，不會搬動或刪掉原本歌曲。若歌曲仍載入，先按歌曲區的取消／卸載再換資料夾。

選擇視窗沒出現時，檢查是否被其他視窗遮住；可按取消資料夾選擇，改用完整路徑。

STEP 03 · 新歌才需要等待

建立歌曲基準

「分離與音高設定 · 遮罩與試聽」預設收起。展開後可查看固定設定、試聽分離結果及編輯不計分遮罩。

  1. 貼上 YouTube 影片網址，選有清楚原唱的版本。
  2. 新歌固定使用完整歌曲（最長 15 分鐘）、RMVPE、Demucs／htdemucs、單次分離、人聲／伴奏分離，並保留分離音軌。
  3. 直接按區塊外的準備歌曲基準，不用展開設定。
  4. 等待已就緒再試聽或開始演唱。分離 100% 之後仍須完成音軌、基準與保存；進度、錯誤與取消按鈕保持在收合區外。

歌曲庫的既有版本仍依原設定載入，不自動轉成新設定。需要重做該版本時用「重新分離並覆蓋」；缺少音軌時用「補建試聽音軌」，兩者都沿用既有版本。一般「準備歌曲基準」則使用上方固定的新歌設定。

首次需要下載模型；GPU 可用時優先使用，失敗時依原有規則改用 CPU。音訊只在本機處理及保存。

STEP 04 · 先用耳朵確認

分離結果試聽

  1. 從歌曲庫載入歌曲，或等待新歌準備完成。
  2. 展開分離與音高設定 · 遮罩與試聽，在分離結果試聽查看「目前已載入」的歌曲、模型與流程。
  3. 按試聽人聲或試聽伴奏，下方播放器可暫停與定位；試聽會暫停 YouTube，不參與評分。
  4. 舊版本若只有基準，按補建試聽音軌。等待就緒後才可試聽。

既有 BS-RoFormer、Mel-Band RoFormer、反向相減、YIN 與片段版本仍可從歌曲庫載入；已有四軌的主唱版本也保留主唱／和音試聽。這些是既有版本相容功能，新歌設定不再提供多種下拉選項。

收起這一區只改變畫面顯示，不會停止正在播放的試聽、YouTube、麥克風或錄音。要停止試聽請使用音訊播放器的暫停鍵。

RMVPE 與既有基準版本

新歌固定使用 RMVPE 擷取歌聲音高，首次下載約 181 MB 的模型，保存於本機並供所有歌曲共用。音高模型不會改變試聽音軌的音色，也不會改變麥克風即時分析方式。

舊 YIN 版本仍保留。從歌曲庫點選版本後，依歌曲庫與試聽來源標示確認實際模型。已保存的其他模型、片段與遮罩不會因本次 UI 整理被改寫。

選用 · 預設沒有遮罩

樂器被認成歌聲？設定不計分區間

  1. 先從本機歌單載入已分離好的歌曲，不需要重新分離。
  2. 展開分離與音高設定 · 遮罩與試聽，找到下方的不計分區間遮罩。建議在開啟麥克風前設定；已有一輪演唱時，先結束並結算才能修改。
  3. 播放到需要排除的段落，按現在位置設為起點，到段落結尾按現在位置設為終點。也可手動輸入秒數或分:秒，例如 32.5 或 1:02.5。
  4. 按新增並保存遮罩，確認顯示「已保存」。可新增多段，重疊或相接的區間會合併。保存失敗時不套用新遮罩，請看錯誤訊息後重試。
  5. 開始演唱後，遮罩區間的右側原唱音符顯示休息，藍色基準線中斷；音準、進拍、完整度都不計入。影片仍正常播放，也不會靜音。
  6. 要調整區間，刪掉該段再新增；按清除全部遮罩即可恢復原本基準的評分。

遮罩自動存到你指定的本機歌曲庫，綁定原始影片與分析範圍。同一影片、同一分析範圍的 Demucs／BS-RoFormer／Mel-Band RoFormer、人聲／主唱模式、YIN／RMVPE 共用一份遮罩；在任一版本修改，其他版本下次載入也會套用，換模型或重做不必重標。只在評分與基準顯示時套用，不裁切音檔。既有舊版遮罩會優先採用最近保存且非空的一份；後續修改即寫入共用檔。

起點包含、終點不包含；實際排除以基準時間格為單位（目前約 0.1 秒），與區間重疊的時間格整格排除。每輪開始後固定遮罩，暫停仍不能修改，結算後才可再改。整首／已演唱兩種評分範圍都適用；如果本輪只經過休息或遮罩區間，不會產生分數。

先在頁面前方的收音設定選擇收音方式與麥克風。桌機第一排左側為 01 歌曲網址與播放器，右側為 03 即時音高與收音；下方依序為聲曲分離與音高旋律擷取、本機歌單、02 錄音後處理、04 看節拍調延遲、05 評分與錄音設定；開啟／停止麥克風位於即時音高區。

評分難度、重新評分難度與歌曲基準、音域比對與評分範圍位於預設收起的評分設定。要調整時先展開；錄音內容、歌聲延時與音量平衡收在「錄音設定」；「從頭開始唱」、「結束並結算」、錄音狀態與分數都在 YouTube 影片下方，維持可見。

STEP 05 · 每輪開始前設定

開啟麥克風，從頭開始唱

  1. 戴上耳機，選好收音麥克風，按開啟麥克風並允許權限。說話時確認音量條與音高有反應。
  2. 在評分難度選標準、嚴格或寬鬆。預設寬鬆，適合輕鬆練唱；標準沿用原本規則，嚴格適合精準練習。每輪開始後固定，分數上方會標示本輪難度。
  3. 在音域比對保留允許高／低八度，男聲唱女聲旋律時可低八度；選嚴格原調才要求與原唱同音高。
  4. 選評分範圍。預設只比已演唱範圍，只評開始至停止的播放區間，區間內的漏唱、跳過仍會扣分。改選整首歌曲才會把提前結束的剩餘段落算漏唱。
  5. 按從頭開始唱。系統開啟麥克風、等待播放器回到 0 秒，再清除上一輪資料開始評分。原本正在播放也會重新開始。麥克風就緒且播放器確認回到 0 秒後，畫面自動捲到播放器，位置會避開上方固定導覽列，不必自己往上找影片。
  6. 保持此網頁在前景。亮色線是你的聲音（冷色調為青色、暖色調為琥珀色）、藍線是原唱基準；允許八度差時兩線不一定重疊。

也可在歌曲基準與麥克風都就緒後直接按 YouTube 播放，從當時的播放位置開始評分。需要每次從頭一致練習，請用從頭開始唱。

即時歌聲輸出

先開啟麥克風，在「即時音高與收音」勾選「即時播放我的歌聲」，並選擇歌聲喇叭。輸出音量預設 30%，只影響喇叭監聽，不改變錄音或評分；YouTube 配樂仍由原本的輸出裝置播放。歌聲輸出預設關閉，停止收音、換麥克風或離開頁面時一併關閉，下次開麥需自行勾選。請先用低音量測試，喇叭遠離麥克風以免回授；本機相容收音配合新版本機工具時，歌聲由 Python 直接以 Windows 共用模式送到所選喇叭，省略瀏覽器回放；狀態會顯示「本機歌聲直送喇叭中」。將歌聲輸出選成與 YouTube 相同的電腦喇叭，即可同時聽到配樂與歌聲，不用更改 USB 麥克風或喇叭接線。監聽音訊若積壓會跳過過期片段；只有監聽分支會丟棄片段，原本錄音串流、混音及 200 ms 歌聲校正保持原行為。200 ms 是錄音成品校正量，不是喇叭回放等待時間。網頁失去監聽控制連線後，本機監聽會自動關閉；輸出裝置故障只停止監聽，收音可繼續。實際延遲仍受音效裝置與系統排程影響。更新此功能需重啟本機工具；舊工具仍使用瀏覽器監聽。若看不到其他喇叭，開麥後按重新整理；瀏覽器收音模式不支援選擇輸出時使用系統預設喇叭。

三種難度怎麼比？

難度音準滿分誤差進拍滿分誤差
標準（原有規則）±25 音分±80 毫秒
嚴格±15 音分±40 毫秒
寬鬆（預設）±50 音分±120 毫秒

100 音分＝1 個半音。超過滿分範圍後逐步扣分；嚴格／標準／寬鬆的單格音準分別在 100／200／300 音分歸零，單個起音的進拍分別在 200／350／500 毫秒歸零。漏唱仍扣分，完整度算法與三項權重相同。

難度、允許高低八度、整首／已演唱範圍是三個獨立設定。改難度不用重新分離歌曲；結算後選下一輪難度，再按「從頭開始唱」。歌曲初次就緒時也可直接按 YouTube 播放，會使用開始當時所選難度；結算後再唱請按「從頭開始唱」。

這些是本工具自訂的練習門檻，尚未經真人評分校準。「標準」不代表業界統一標準；分離品質與收音延遲也會影響分數。歷史紀錄仍只保存歌名與分數，不另保存難度，跨難度的歷史分數不宜直接比較。

評分是音準 60%、進拍 25%、完整度 15%。不辨識歌詞；唱錯字但音高相同，無法據此判定。設定在本輪開始後固定，下一輪可再改。

STEP 06 · 唱一段也能結算

停止、結算與再唱一次

操作會發生什麼事
暫停 YouTube暫停評分；緩衝時也不計分。
停止收音停止並保存本輪錄音，釋放麥克風，播放器暫停並回到 0 秒；保留本輪評分資料，可再按結束並結算。
結束並結算結算本輪、保存分數，並停止與保存本輪錄音（若有啟用）；歌曲基準與試聽仍保留，可直接再唱。
從頭開始唱麥克風與播放器就緒後，清除上一輪尚未結算的演唱資料，自動捲到播放器，從 0 秒重新計分。
YouTube 播完有進行中的演唱時會自動結算。

只分析前 30 秒時，播放超過 30 秒就不再累計該基準之外的聲音，但不會強制結算或停止影片。中途結束仍按結束並結算。

只試麥克風、尚未開始歌曲評分時，不會產生一輪分數。切到其他分頁或裝置中斷會停止收音，回來需重新開啟；已有演唱資料仍可結算。

演唱錄音儲存、錄音歌聲延時校正與音量平衡，統一放在預設收起的錄音設定；錄製前展開調整，收起後仍保留設定。錄音狀態、開始／結束按鈕及本輪分數集中在 YouTube 影片下方。

演唱錄音與分數紀錄

  1. 展開錄音設定，找到演唱錄音儲存。錄音內容有「歌唱者」與「歌唱者＋配樂／和音」（預設）兩種，也可選「不保存錄音」關閉錄製。此瀏覽器會記住選擇；選不保存後只收音評分，不啟動錄音器。
  2. 在錄音音量平衡，預設不勾選「手動設定比例＋自動微調」，由系統自動平衡歌唱者與配樂／和音，各路最多修正 ±6 dB。勾選後可先調歌唱者、配樂／和音音量（0–100%），系統以這個設定為基礎，只微調 ±3 dB；0% 保持靜音。兩個百分比是各自音量，不必加總為 100%。設定會記住，每輪開始後固定；歌唱者模式不使用配樂／和音滑桿；配樂與和音合為一路調整，保留兩者相對比例。
  3. 混音需已保存分離音軌；沒有時先補建。系統依已載入版本判斷：一般兩軌版本加入伴奏；主唱／和音四軌版本加入伴奏＋和音。兩條音軌同步跟隨播放、暫停與跳轉；缺少應有音軌時會提示補建，不會偷偷省略和音。不加入原唱主唱或全部人聲，也不擷取 YouTube 網頁聲音。錄音清單會標示有無獨立和音。請戴耳機，避免喇叭聲再漏進麥克風。
  4. 按從頭開始唱，完成麥克風與播放器同步後，影片播放時開始錄音。暫停或緩衝時錄音也暫停；跳轉會跟隨新位置，儲存的是實際演唱順序。歌唱者模式完全不混入伴奏或和音。
  5. 按停止收音、結束並結算或等影片播完，會自動停止並保存錄音，並在「錄音後處理」自動選取剛保存的那一筆，同步更新評分區的錄音選擇。重按「從頭開始唱」會先保存上一段，再另開一段，不覆蓋；只按 YouTube 播放或單獨測試麥克風不會另開錄音。
  6. 在錄音後處理區塊展開所有演唱錄音，可試聽、下載或刪除個別錄音。桌機 Chrome／Edge 通常保存 WebM／Opus 音訊。錄音完成後存於本機歌曲庫的「錄音」子目錄；未搬存成功時仍留在瀏覽器，請看錄音位置訊息。
  7. 展開分數紀錄 · 勾選清除，勾選需要刪除的紀錄，按清除勾選紀錄；可全選，也可直接按全部清除。這些操作只刪分數，錄音與歌曲庫不受影響。

伴奏只涵蓋準備歌曲時的分析範圍；超過音軌長度後，錄音仍會繼續保存歌聲。錄音的自動音量採平滑調整，低於門檻或未偵測到穩定歌聲時不自動增強麥克風；輸出有壓縮及峰值保護。這是音量平衡，不是自動 EQ；無法修復麥克風本身已經破音的訊號。混音不加入音高評分的麥克風訊號，遮罩也只影響評分，不會把錄音消音。藍牙與裝置延遲仍可能造成聽感上的不同步。

切到背景或換裝置會停止收音並嘗試保存。錄音期間約每秒把音訊片段存入本機資料庫；意外關閉時只能保留已寫入的片段，清單會標示未正常結束。儲存空間不足時會顯示「下載未保存錄音」，請在關閉頁面前下載備份。

STEP 07 · 下次不用重新分離

載入、重做與刪除

  1. 按主畫面上方的歌曲庫，會自動捲到獨立的本機歌單區並展開歌單；也可直接點本機歌單 · 點一首就載入的大字亮色標題展開或收合。下方顯示已保存的基準數量，必要時按重新整理歌曲庫。
  2. 點歌曲名稱直接載入；會卸載前一首的記憶體工作，但不刪除前一首保存的資料。
  3. 要重做：從歌曲庫載入要重做的版本，再按重新分離並覆蓋。會跳過快取，成功後才替換同一影片、範圍、模型、流程、音高方式、模式的結果。
  4. 要移除：按該筆的刪除，會刪掉這筆基準與試聽音檔。其他模型、範圍或模式的版本不受影響。

如果新分離失敗，新產物會清除；已保存的舊結果在新結果成功前保留。不同模型、分析範圍與分離模式是不同筆。要切換既有版本，從歌曲庫載入對應項目。

進行中的演唱請先結束並結算，再重做、補建或換歌。歌曲區取消／卸載釋放目前工作，不等於刪除歌曲庫。

STEP 08 · 選用

五音延遲測試

支援的 Chrome／Edge 中，麥克風分析採「不開啟喇叭輸出」模式，YouTube 獨立播放。只有五音測試會暫時啟用分析器的聲音輸出；測試結束或取消後恢復。可在「收音裝置與狀態」查看分析輸出模式。

評分的手動時間補償預設為＋200 ms，將歌手聲音提前 0.20 秒比對：10.200 秒的歌聲對照 10.000 秒的歌曲基準。更換收音裝置後回到此預設，可再手動調整或測試。評分補償與錄音校正各自預設 200 ms，分別用於比對與音檔，不會加成 400 ms。

  1. 開啟麥克風，先展開看節拍，調延遲，再展開Do Re Mi Fa Sol 五音延遲測試。
  2. 選跟唱，或把耳機／喇叭靠近麥克風的聲音回收模式；再選適合的高低音域。
  3. 按播放五音並測試，跟唱或讓麥克風收回測試音。
  4. 穩定辨識至少 4 個音才提供建議；按套用建議補償才會改動數值。也可手動調整。

跟唱結果包含人的反應時間；聲音回收測的是網頁音訊往返時間，可能與 YouTube 不同。補償只調整評分比對位置，不會消除藍牙耳機本身延遲。換裝置後重新測試，先用有線設備較容易比對。

錄音後處理：調延時，不必重唱

錄音選單下方的「試聽／下載／後處理／刪除」只操作目前選取的那筆錄音；後處理會移到延時與音色設定，刪除前需確認。

歌曲基準、重評難度、延時重評與評分診斷集中在「評分設定」的「錄音重新評分」。重新合成、歌聲柔化與 MP3 下載在「錄音後處理」。兩區的錄音選擇與延時欄位同步，難度預設寬鬆。

試聽完整成品或只聽人聲

選取錄音後，按「試聽」播放完整成品，按「只聽人聲」單獨聽歌唱者，不加入配樂或和音。人聲試聽沿用這筆錄音已保存的音量、延時及柔化效果；調整設定後請先重新合成，才能試聽新效果。人聲試聽不另存錄音，也不需要歌曲庫配樂。舊混音若未保留原始歌聲，這個按鈕會停用。

調整主唱與配樂音量

選取可後製的錄音或新版成品，調整「歌唱者音量」和「配樂／和音音量」。100% 沿用錄音時的平衡，0% 靜音，最高 200%；兩個百分比不必相加為 100%。配樂和和音共用音量，純歌聲錄音無配樂可調。按「重新合成（音量／延時／音色）」後另存並試聽；調整滑桿不會即時改變已播放的成品。每一版會保留獨立的原始歌聲與目前設定，後续可以繼續後製、關閉柔化或重新調整音量。調高音量仍會經過峰值保護。

人聲進階後製

展開「人聲進階後製」，四項預設均為關閉或中性。局部音量：按「新增區段」，依錄音播放器秒數填開始、結束與人聲音量；100% 不變、0% 靜音、最高 200%，區段不可重疊。秒數不是 YouTube 時間，改延時後請重新核對區段。EQ：低頻控制厚度、中頻控制存在感、高頻控制明亮度，先從 ±2～3 dB 比較。動態壓縮：輕度保留較多起伏、中度更穩定。殘響：0% 關閉，最高 100%；尾音長度可調 0.2–10 秒，預延遲可調 0–500 ms。原版預設為 0.8 秒／15 ms。

這些效果只套用歌唱者，配樂／和音不套用。按「重新合成」另存後，可用完整試聽或「只聽人聲」比較。每筆成品保存自己的設定，選取後可繼續修改；每次從原始歌聲重算，效果與尾音不累加。可用「重設全部人聲效果」撤回，再重新合成。局部音量的區段外仍可能聽到前段自然延伸的殘響；整體歌唱者音量 0% 則連殘響一起靜音。

歌聲柔化：先從輕度比較

  1. 選擇有保存原始歌聲的錄音，確認可重新合成。
  2. 設定延時；若只想比較音色，保持與原成品相同的校正量。
  3. 「歌聲柔化」預設關閉，可選輕度（柔和一點）、中度（明顯溫潤）或強烈（厚柔、較暗）。可直接比較關閉與強烈，再選喜歡的程度。
  4. 按「重新合成（音量／延時／音色）」，完成後會另存一筆，清單及下載檔名標示柔化強度，原錄音保留。
  5. 按下方播放器試聽；滿意後可轉 MP3。成品可繼續後製；要比較其他強度，保持同一音量與延時重新合成。

第二版柔化結合高頻降低、中高頻凹陷與高頻截止，讓三種強度有更明顯的音色差異，再以動態等化進一步降低尖亮片段，只處理歌唱者聲軌，不修改配樂、和音、音高基準或評分。它不是呼吸聲消除，也不能保證去除氣音或修復破音；強度太高可能影響音色與咬字。重新評分仍使用原始歌聲。新版成品另存時會保存自己的原始歌聲與後製資料，可直接再次編輯。舊成品若沒有原始歌聲，仍需回到來源錄音操作。

新錄音的錄音歌聲延時校正預設為＋200 ms：停止後自動將成品歌聲提前 0.20 秒，配樂與和音保持原位，校正成品保存為 WAV；錄音清單與下載檔名會標示實際套用的校正量，預設後綴為 +200ms（例如 歌名+200ms.wav 或 歌名+200ms.mp3），只重新評分不會改變音檔後綴；乾淨原始歌聲保留原格式與時間。每輪開始前可調整，填 0 表示不校正。這項錄音設定不改動即時評分的時間補償。後處理預填本輪錄音校正值，每次都從未校正的原始歌聲重算，不會再疊加 200 ms。舊錄音與既有校正成品不會自動改寫；若自動校正失敗，保留未校正錄音並顯示原因。

既有錄音搬存：更新並重啟本機工具，網頁按 Ctrl＋F5。系統會自動將目前瀏覽器的既有完整錄音搬到歌曲庫下的「錄音」目錄；也可按「重新整理／搬存錄音」重試。確認「錄音位置」顯示實際路徑與搬存完成，才算完成；失敗時保留瀏覽器原檔，請勿清除網站資料。Chrome 與 Edge 各自原有的錄音須分別開啟一次網頁搬存，搬存後兩者共用硬碟清單。切換歌曲庫位置會切換錄音目錄，原資料夾仍保留。

刪除：錄音清單可逐筆刪除，或按「全部刪除錄音」並確認。會刪除對應音檔、乾淨歌聲、重評資料及已轉 MP3；全部刪除也包括清單中的重新合成成品。歌曲基準與分離音軌不受影響。刪除不能復原，重要資料請先備份整個錄音目錄。

  1. 新版錄音除了成品，也會保存乾淨歌聲、播放時間位置、音高觀測與當次基準／遮罩／評分設定。錄製時先暫存於瀏覽器，停止後搬到目前歌曲庫下的「錄音」子目錄，例如 D:\歌單\錄音。每筆錄音各自一個目錄，包含 metadata.json、mix 音檔及有保存時的 voice 音檔；轉 MP3 後也會保存 export.mp3。選「不保存錄音」不會保留這些資料。
  2. 到主畫面最下方錄音後處理，選擇已保存的錄音；也可在錄音清單按「後處理」。
  3. 舊錄音不會自動換基準。預設重評仍使用錄製當時的基準。想比較 RMVPE：先在歌曲庫載入同一影片、同一分析範圍的 RMVPE 版本；新歌固定建立完整歌曲的 RMVPE 版本；若原錄音是片段，請使用已保存且相同分析範圍的版本，不能用全曲版本取代。等到顯示「已就緒」及 RMVPE，再到錄音後處理選回原始錄音，將重新評分使用的歌曲基準改為目前已載入的歌曲基準。核對下方顯示的版本後重評，不必重唱。必須完成歌曲庫版本載入；另一支影片或不同分析範圍不能套用。結果會標明實際使用的音高方式與可計分旋律秒數；0 ms 對照也使用相同基準。重評會保存所用基準快照，錄音原始基準、遮罩、評分設定及混音配樂來源保留。切回「錄音當時的基準」即可再次比較。
  4. 選重新評分難度：嚴格、標準或寬鬆。每次選取錄音時預設為寬鬆，於「評分設定」調整。同一筆錄音可切換難度重評，不必重唱，不改寫原始評分設定或音檔。
  5. 輸入歌聲延時校正：＋100 ms 代表歌唱者聲音往前移 0.1 秒，−100 ms 則往後移。配樂與和音不移動。數值是總校正量，每次都從原始資料計算，不會累加；初始值沿用本輪錄音校正值；舊錄音沿用當時保存的時間補償。
  6. 按調延時重新評分，直接從已保存的乾淨歌聲音檔重新擷取音高，依重混所用的同一播放時間軸與所選基準比對；難度使用「重新評分難度」的選擇；八度、評分範圍與遮罩沿用當次設定。結果會標示並保存所用難度，0 ms 對照也使用同一難度。新結果保存於這筆錄音，原始成績紀錄保留。首次重評會在瀏覽器背景分析原始歌聲，之後改延時可重用分析，不需重唱。畫面會同時顯示相同音檔在 0 ms 的進拍分數，方便比較；不再使用舊的即時音高時間戳判定錄音進拍。即時及重新評分皆以最接近基準時間點的音高觀測比較，避免格尾取樣偏差；更新後可直接用既有後處理錄音重評，不需重唱或重做歌曲基準。
  7. 按2. 調延時重新合成，將乾淨歌聲移到新位置，依原錄音模式混入伴奏及獨立和音。配樂與和音共用音量；沿用錄製時的手動／自動平衡設定，離線重新計算音量。暫停部分不保留，跳轉則依實際演唱順序合成。提前會裁去開頭超出位置的歌聲；延後會保留尾端。
  8. 完成後另存一筆 WAV 錄音，原錄音不覆蓋。按播放鍵試聽，再按轉 MP3 並下載。要繼續調整，可直接選取這筆成品；音量、延時與柔化設定會預填，每次從保留的原始歌聲重算，不會疊加效果。若重評進拍與試聽明顯矛盾，按「下載這筆評分診斷」可匯出單筆 JSON，包含原錄音、乾淨歌聲、時間位置及基準。檔案只下載到本機；提供此檔才能檢查實際對齊，不需重唱。也能直接將未校正的原錄音轉 MP3。

MP3 由本機工具的 FFmpeg 轉成 192 kbps；只傳至這台電腦的 localhost，不上傳雲端。首次使用這功能需更新並重新啟動本機工具。轉檔暫存檔在完成或失敗後清除。重合成配樂需保留相同版本的歌曲音軌；歌曲庫搬移時請選回原資料夾。

舊錄音或舊成品若沒有獨立歌聲／時間資料，仍可下載與轉 MP3，但無法直接分軌後製。新版成品各自保存原始歌聲、時間資料及後製設定，刪除上一版也不影響再次編輯；歌曲庫的同版本配樂仍須保留。單獨匯出的 WAV／MP3 不包含這些編輯資料，請保留歌曲庫「錄音」中的完整目錄。新錄音若未正常保存，後處理會停用。清除錄音時也會刪除其乾淨歌聲與評分資料；另存的合成版本獨立保留。音高偵測、分離品質與瀏覽器時間誤差仍會影響結果。

剪輯、淡入淡出與進階殘響

  1. 在「錄音後處理」選擇錄音，按「後處理」，展開剪輯與淡入淡出。
  2. 輸入保留的開始與結束秒數，也可試聽後按「目前位置」設定。秒數以剪輯前的完整錄音為準；已剪輯版本會自動換算播放器位置。結束留空會保留到尾音結束。
  3. 設定淡入與淡出秒數（各 0–30 秒，合計不可超過保留長度），會一起調整人聲和配樂，讓開頭與收尾平順。
  4. 在人聲進階後製中調整殘響量（0–100%，數字越高，加入的殘響越明顯，原本人聲仍保留），並選擇原版、房間、大廳或板式空間。切換空間會先帶入建議值；尾音可調 0.2–10 秒，預延遲可調 0–500 ms。預延遲控制人聲發出後多久開始出現殘響，不是歌聲對齊配樂的延時校正。
  5. 按「重新合成（音量／延時／音色／剪輯）」另存，再試聽。新檔名會標示剪輯、淡入淡出與殘響設定；「只聽人聲」也使用已保存的效果及剪輯。

明確指定結束時間會裁掉該時間之後的殘響。若要讓尾音自然結束，請保留足夠長度或將結束留空。剪輯不會改動原始歌聲；按「重設剪輯」再合成可恢復完整長度。人聲效果另有重設按鈕，兩者分開操作。

每個新版成品保留獨立的原始歌聲及設定，反覆後製不累加效果，刪除上一版仍可重編（混音需保留歌曲庫配樂）。重新評分仍依完整原始演唱，不因剪掉片段而改變評分範圍。單獨下載的 WAV／MP3 不包含還原資料，請保留歌曲庫中的完整錄音目錄。

片段試聽、A／B 比較與局部效果

  1. 選取一筆可後製錄音，展開「片段試聽／A、B 比較」。以剪輯前完整錄音的秒數填入同一句起訖，每段最多 30 秒，可選混音或只聽人聲；也可先播放成品，再按「從目前播放位置取 10 秒」。
  2. A（藍色）起初保存這筆錄音原有的音色設定；B（紫色）帶入目前後製設定，預設調整 B。點 A／B 標籤或編輯區切換鈕，全部音量、延時及效果欄位會換色並帶出該組數值，兩組各自保留調整。「試聽目前設定」播放目前編輯的組別。欄位未填完整時會保留原畫面，修正後再切換。
  3. 使用並排的 A／B 大按鈕切換，A 為藍色、B 為紫色，播放中的組別會反白並顯示「正在聽」。下方設定採 A／B 標籤，點選只展開該組，可用左右方向鍵切換標籤；首次需準備音訊，之後沿用相同播放位置並循環播放。近似音量匹配會降低較大聲的一組，只影響比較，不改變成品。
  4. 喜歡哪組，就按該組「套用到後製」，再到下方按「重新合成」另存。A／B 試聽不寫入錄音清單；切換錄音或重整會清除比較暫存。試聽暫不套用剪輯與淡入淡出；成品仍按剪輯設定合成。

殘響明亮度：負值柔暗、正值明亮，0 沿用空間預設。殘響立體寬度：0% 集中在中央，100% 保留完整左右差異。兩者只改變殘響，不改原本人聲。

回聲 Delay：可調音量、80～1000 ms 重複間隔、1～8 次重複、每次保留音量及左右交替。每次保留 40% 代表後一次是前一次的四成；0% 只留下第一次。與殘響同時使用時，兩種效果分別從人聲產生。

局部效果：按新增效果區段，設定開始、結束、殘響音量、尾音長度與回聲音量。可讓主歌較淡、副歌較濃，或只在最後一句拉長尾音；最多 20 段且不可重疊。區段外沿用上方設定，已產生的尾音自然延伸到區段外。明亮度、寬度、空間與回聲間隔仍沿用全域值。

所有新效果都可由「重設全部人聲效果」撤回，再從原始歌聲重新合成；已保存的原錄音保留。

開麥後伴奏變小聲：本機相容收音

  1. 啟動更新後的本機工具；需安裝 SoundCard（包含在 tools/requirements-audio.txt）。
  2. 先展開頁面前方的「收音設定」，將收音方式選為「本機相容收音」。選擇你的麥克風。
  3. 按「開啟麥克風」。首次若 Windows 詢問 Python 麥克風權限，請允許。
  4. 播放影片確認音量正常、收音音量有反應，再按「從頭開始唱」。評分與錄音操作相同。
  5. 按停止收音、離開前景或關閉分頁會停止本機收音。工具中斷時會顯示錯誤，請重新開啟。

此模式避開瀏覽器直接開啟硬體麥克風的路徑。聲音只在本機 Python 和本機瀏覽器之間傳遞，不上傳雲端；未選保存錄音時不寫音檔。模式選擇會記住，下次仍需按鈕才開始收音。改用此模式會增加串流緩衝，請用延遲測試或後處理重新核對時間補償，不要直接沿用舊測量結論。同一時間只允許一個分頁使用本機相容收音。

遇到問題，依序檢查

按從頭開始唱沒反應／沒有收到聲音

先看麥克風狀態。在 Chrome／Edge 網址旁的網站權限允許麥克風，再確認 Windows 麥克風權限、輸入裝置與音量。回到頁面按開啟麥克風；看到音量反應後再唱。若等待 YouTube 同步，確認播放器已載入且沒有錯誤提示。

做了分離卻沒有試聽音軌

已保存的舊結果可能只含數值基準。展開分離結果試聽，按補建試聽音軌，等到已就緒；或保持保留音軌勾選，重新分離並覆蓋。主唱與和音兩個按鈕只出現在已載入主唱模式的歌曲。

舊版主唱／和音音軌如何試聽？

從歌曲庫載入已保存的主唱版本，再展開「分離與音高設定 · 遮罩與試聽」。主唱與和音按鈕依該版本顯示；缺少音軌時先補建。新歌固定使用人聲／伴奏分離。

按從頭開始唱後，沒有自動捲到播放器

自動捲動發生在麥克風與播放器同步成功後。若仍等待麥克風授權、授權遭拒或 YouTube 同步失敗，先查看收音區與評分區的提示。允許麥克風並確認播放器可播放後，再按一次「從頭開始唱」。

只唱一小段，分數卻很低

目前預設「只比已演唱範圍」。如果曾切換到「整首歌曲」，開始前改回來；整首模式會把沒唱完的部分算漏唱，本輪開始後不能事後變更範圍。也要試聽基準、確認麥克風與延遲，不能只靠總分判定原因。

本機工具無法連線／主唱分離缺少套件

確認已執行 start-local.ps1，允許本站本機網路權限。升級進階分離需更新程式、停止工具、重跑 setup-local.ps1，再啟動；之後 Ctrl+F5 重新整理網頁。只有更新雲端網頁，不會自動安裝每台電腦的 Python 套件。

BS 分離到 100% 後顯示 WAV 編碼不支援

舊版在處理 MP3 輸入時可能於匯出音軌失敗。更新本機工具程式碼後，停止並重新啟動工具，再重新準備歌曲；模型不必重新下載。失敗的新結果未保存，舊歌曲版本仍保留。修正版會先解碼輸入，避免混用壓縮編碼與 WAV。

一直顯示取得 YouTube 音訊

本機下載工具與 YouTube 播放器使用不同的連線；能快速播放影片，不代表本機已取得整首音檔。新版每次下載先檢查 IPv6 連線（最多 2 秒）；檢查未通過時，自動切換 IPv4 並顯示原因。若 IPv6 檢查成功、後續下載出現連線錯誤，也會改用 IPv4 重試一次。403／429、登入限制或影片不可用仍會顯示錯誤，不當作 IPv6 故障。下次工作會重新檢查，因此 IPv6 恢復後可再使用；不修改 Windows 或瀏覽器網路設定。更新本機程式並重新啟動本機工具後生效，已在下載的工作仍使用啟動時的設定。若仍失敗，請保留錯誤訊息供診斷。已保存且音軌完整的同版本歌曲，按準備會直接重用；刪除後重新準備則會重新下載。

分離很久、百分比不動

首次可能正在下載模型；CPU 處理整首歌也比較久。查看目前階段及 GPU／CPU 標示。無實際百分比的階段不會假造進度。新歌固定分析完整歌曲；需要中止時按取消／卸載。

和音仍被當成主唱／主唱被切掉

主唱／和音模型可能判錯。先切換試聽主唱、人聲，確認哪個較符合歌曲；可回到預設人聲／伴奏模式建立或載入基準。此工具仍是練習用，無法保證每首歌都準確分離。

資料留在哪裡？

  • 你指定的歌曲庫：影片識別資料、歌名、分析範圍、分離模型與模式、數值基準、不計分區間遮罩與選用試聽音檔。可由歌單載入對應 YouTube 影片。
  • 工具資料夾：套件、模型與處理期間的暫存。模型與歌曲庫分開：Demucs 在 .runtime/models 下，BS-RoFormer 在 .runtime/models/bs-roformer，Mel-Band RoFormer 人聲模型在 .runtime/models/mel-roformer，主唱／和音模型在 .runtime/models/lead，RMVPE 音高模型在 .runtime/models/rmvpe。模型由所有歌曲共用，更換歌曲庫不需重新下載。原始混音與大型分離 WAV 在網頁工作完成後清理。
  • 這個瀏覽器：最近的歌名與分數紀錄，以及錄製中／尚未搬存成功的錄音暫存。完整錄音、後處理資料及 MP3 存於歌曲庫下的「錄音」目錄；Chrome 與 Edge 連線同一本機工具即可共用。
