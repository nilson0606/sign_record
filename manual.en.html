A guide for desktop Chrome and Edge on Windows. The website provides the interface; local tools process audio on your computer. Traditional Chinese is the default. Choose English in the page header to remember your preference in this browser. The header’s Theme menu offers Console (the default, matching the AI Cover console look: raised panels, recessed inputs, fader-style sliders and a one-line intro), Tech blue and Warm; this browser remembers your choice.

Daily workflow

  1. If you started with the AI Cover workstation's sign2mv.bat, Sing & Record is already running: click Open Sing & Record → on its home page. Otherwise, run .\start-local.ps1 in your tools folder, then click Check local tools on the website.
  2. Choose your input mode and microphone. Enable the microphone and test your voice with headphones.
  3. Load a prepared library song, or import media and prepare its reference. Check the song key.
  4. Choose guide vocals and recording levels, then record the whole song or individual segments.
  5. Preview your take. For segment mixed previews, adjust vocal and backing levels while listening. Save for post-production when satisfied.
  6. Compare effects with A/B, render a new result, then download audio or create a music video.

Install once, start each session

Use the Download the local tools link in the website’s local-tools panel. Extract the package to a permanent folder. Install Node.js 22 or later and the Python version specified by the setup instructions. Open PowerShell in that folder.

.\setup-local.ps1

Let setup install the required packages and models. Audio stays local. Start the tools after setup and after each computer restart:

.\start-local.ps1

Keep the tools running while using the website. Allow browser microphone and local network access when requested. Restarting the computer does not uninstall the tools. Additional features may require their own local models and dependencies; use the status shown in each panel.

Choose your song library

Click Choose folder, or enter a full folder path and click Use this location. The computer remembers it. Changing locations does not delete the old library. Cancel or unload a song before switching locations. Models are stored separately from the song library and are shared across songs.

Prepare a song and choose its key

  1. Select YouTube, local video, or local audio. Paste a YouTube URL (it loads automatically after about half a second; it will not switch while you are singing or recording), or choose and import a local file. Local files are limited to 2 GB and 15 minutes; the original file is retained.
  2. Choose the key, from −12 to +12 semitones. Tempo stays the same. The default is the original key.
  3. Click Prepare song reference. Wait until the status says ready; 100% separation alone is not the end of preparation.

New songs default to full-song analysis, RMVPE pitch extraction, and retained preview stems. Advanced settings offer other models, short test ranges, and workflows. Changing model, mode, or key creates or loads the corresponding version. Different key versions keep separate recordings and segment drafts.

RMVPE and existing versions

Changing the pitch extraction setting alone does not load a new reference. Prepare the reference to apply it. Compatible retained stems can be reused without separating again. Existing songs remain available in the library.

Preview the separated stems

Preview vocals and instrumental to check separation. A lead / harmony version also offers separate lead and harmony previews. Choose this mode before preparation if “Backing only” playback should keep the original harmony vocals. Separation can make mistakes, so listen before committing to a long conversion.

If a song has only scoring data, use Rebuild preview stems. Stem preview pauses YouTube and does not score your voice.

Exclude incorrect reference regions from scoring

Load a reference, find an instrumental or misidentified passage, and enter its start and end in seconds or min:sec. Add and save the mask. Masked regions show Rest and do not count toward pitch, timing, or completeness; the video continues normally. Masks save locally, are shared across models for the same media and analysis range, and are fixed for the current singing round.

Record a whole song

Choose browser capture, or native capture if enabling the microphone lowers your backing audio. Native capture requires the local Python capture environment. Enable the microphone and check input first.

Select original vocals + backing, or backing / harmonies only for guidance. This is separate from what the recording saves. Choose singer-only, mixed recording, or no recording in the recording settings.

Click Sing from the start. Recording starts with playback and pauses during pauses or buffering. Playing YouTube directly only scores; it does not begin a recording.

Stop, review, then approve

Stop input, finish and score, or let the song end. Whole-song takes are kept under Pending review. Preview or delete a take, then Save for post-production when satisfied. A pending take remains available without being promoted to a finished result.

Record and replace individual segments

  1. Load a song and enable segment mode. Click Split here during playback to create boundaries.
  2. On the timeline, the selected segment is bright and the others are dimmed; the segment being recorded blinks. Drag a boundary, enter an exact mm:ss.sss time, or step it earlier / later. Preview three seconds either side of a boundary. Segments must remain continuous and at least 0.1 seconds long.
  3. Select a segment. Choose pre-roll (default 5 seconds) and tail allowance (default 2 seconds). Loop practice does not record.
  4. Click Record this segment. It saves automatically after the tail, or use Stop / Save. Record as many takes as needed.
  5. Choose a take for each segment. Preview the selected take with vocals + backing, enable manual levels, and adjust the 0–200% vocal and backing sliders while listening. Playback continues from the same position.
  6. Assemble the full mix. You can also adjust levels during this preview. Save for post-production or download WAV to render the latest levels. An already assembled mix can save the latest levels directly.

Original takes are kept, so level changes do not require another performance. Raw vocals-only preview plays the original input without balance or timing correction. If a region has no usable take, record it or explicitly allow silence. Changing take selections, boundaries, timing, or original-vocal regions requires a new assembly.

Draft boundaries and selections are stored in the current browser; takes are saved in the library. Clearing this song’s segment recordings preserves boundaries, other songs, whole-song recordings, and saved production results.

Add original vocals to parts of a segment mix

Under original vocal regions, enter start and end in song time and choose Original + my recording or Original only. Regions cannot overlap. The current segment’s times can be filled in with one button.

These regions apply to the full mixed assembly. Outside them, your own vocals are used, with continuous backing. Original vocals use the current song key and do not receive microphone correction. Raw vocal preview ignores these regions. Save the draft and assemble again after editing them.

Preview, compare, and produce

Select a saved recording. Preview plays its finished mix; Vocals only plays the separate singer track with saved production settings. Settings changed afterward require rendering before the finished player reflects them.

A/B comparison

A and B start with the recording’s saved settings and can be adjusted separately. B is selected initially. Select the same phrase, up to 30 seconds, and switch A/B previews at the same playback position. Optional loudness matching reduces the louder version for comparison only. Trim and fades are shared and are not applied in clip comparison. Switching recordings or reloading clears temporary A/B edits.

Levels, timing, and effects

100% preserves the recorded balance; 0% mutes. Positive timing correction moves late vocals earlier; negative values move early vocals later. Enter a total correction, not an additional increment. Backing stays fixed. New recordings default to 300 ms correction.

Available vocal processing includes smoothing, EQ, compression, reverb, delay, region levels and effects, noise reduction, de-essing, breath reduction, and pitch correction. Try short clips and change one control at a time. Mood presets change tone; space presets change reverb and delay. Cleanup and pitch correction have independent controls.

Region times use the full recording after timing correction and before trimming, not YouTube time. Regions cannot overlap. Recheck them after timing changes. Reverb tails can extend beyond regions.

Save your preferred version

Select A or B, set trim and fades, then Render again. This saves a new editable result while preserving the original. Processing always starts from the original vocals, so effects and trimming do not accumulate. Leave the trim end blank to keep the full reverb tail. Download WAV or convert to MP3 afterward.

Recording correction and scoring compensation

These are separate settings. Recorded vocal timing correction defaults to +300 ms and moves vocals earlier in the finished audio. Original vocals remain available for production. Manual time compensation defaults to +200 ms and changes live scoring comparisons only.

The optional Do Re Mi Fa Sol test measures singing response or speaker-to-microphone loopback. Review the suggested value before applying it. It does not save audio. Bluetooth, USB, wired, and built-in devices can differ; changing microphones resets scoring compensation to its starting value.

Relaxed difficulty is the default. Choose standard or strict, octave tolerance, and performed-only or whole-song scoring before a round. Pauses are unscored, but missed and skipped parts reduce the score. Rescoring uses the original recording data and your selected reference and difficulty; audio production does not rewrite the performance score.

Create a cover music video

Select a saved recording and click Create music video. Enter the song title and singer name. The video uses the selected finished audio with its saved levels, effects, and trim. Render production changes before selecting the source. All videos you made are in 🎬 Saved music videos (in post-processing, collapsed by default): expand it to list the videos this tool made in the library’s vedio folder, newest first, with song · singer, date and size. Search by song or singer, click Play to preview below, Download to save a copy, or tick videos and click Delete selected videos and confirm to delete them permanently (recordings and original audio are kept). Clear all music videos, next to the recording list, removes every generated video in the current library without selecting a song first; it shows the count, size and location for confirmation, then reports what was deleted and the space freed. Original videos, songs and recordings are kept. Deletion is permanent and does not go to the Recycle Bin.

Output is a 1080p, 30 fps MP4 with an animated spectrum, supporting 1 second to 10 minutes. Videos save in the library’s vedio folder and can be previewed or downloaded.

Saved data and cleanup

The library stores song references, optional stems, recordings, and finished results. Browser recordings are migrated only after the local copy is verified. If migration fails, the browser copy is kept. Chrome and Edge can share local recordings through the same tools and library, but browser preferences and segment drafts remain browser-specific.

Deletion dialogs describe their scope. Pending takes, segment takes, production recordings, backing tracks, diagnostic data, temporary conversions, and music videos have separate cleanup controls. Deletions are permanent. Active conversion files and the current preview are protected by temporary-file cleanup.

Troubleshooting

  • Local tools offline: run start-local.ps1, keep its window open, and check local network permission. The website alone does not install or start audio tools.
  • Microphone denied: allow it in the browser’s site permissions. Check the selected input device and enable it again.
  • YouTube player failed: click Load video again. Some videos block embedding or require sign-in; try another source. A player failure does not delete local references.
  • Missing stems: load the correct song version and rebuild preview stems. Backing-only guidance and mixed production need those files.
  • Levels seem unchanged: raw vocal preview ignores mix balance. For live segment mixing, select vocals + backing and enable manual levels. For saved production, render again after editing.
  • Old interface: reload the page after a release. If a feature requests newer local tools, update and restart them too.
  • Interrupted recording: inspect recording status and download any retained unsaved audio before closing the page. Diagnostic exports may include your vocals.

Data and usage

Microphone analysis, separation, recordings, and production run locally. The website and external media still require their normal network connections, and setup downloads dependencies and models. Your library and recordings are not uploaded by this tool.

This tool is for local testing and personal non-commercial practice. Process only content you own or are authorized to use, and follow applicable laws and platform rules. The tool provides neither songs nor usage rights. Automatic separation, analysis, and scoring are experimental and may be inaccurate.
