收音設定 收音方式 · 麥克風選擇

本機相容模式由這台電腦的 Python 收音，需要啟動本機工具並允許 Python 麥克風權限。聲音只送回本機瀏覽器；仍依下方錄音選項決定是否保存。切換收音方式後請重新測試延遲。

第一次允許收音後可選裝置。建議先用有線耳機或 USB 麥克風測試。

安裝／啟動說明（Windows）
  1. 下載本機工具包，解壓縮到固定資料夾。第一次需先備妥 Python 3.12、Node.js 22 以上 與 FFmpeg。
  2. 在該資料夾開啟 PowerShell，第一次執行：powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-local.ps1工具與模型會安裝在本機，不會上傳你的音訊。
  3. 每次重開機後啟動：powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1回到此頁點「檢查本機工具」。如果瀏覽器詢問本機網路存取，請允許。

重開機不會移除安裝。只有關閉本機工具、重開機後未啟動，或連線權限被拒絕時，需要重新連線。Windows 重設／重灌後可能需要重建。

        05 評分與錄音設定

        練習評分
        評分設定 難度 · 音域比對 · 錄音重評

        放寬八度差不會改變 YouTube 伴奏。其他音高偏差仍會扣分；演唱開始後固定本次模式。

        選「已演唱範圍」時，後面尚未唱到的部分不扣分；這段期間的漏唱、跳過仍計入。每輪開始後固定，重唱時可重新選擇。

        錄音重新評分

        選取錄音後預設為寬鬆；可在此調整，按下方「調延時重新評分」。遮罩、八度及評分範圍仍沿用錄音當時設定。

        正值：歌聲晚到，將歌聲提前；負值：歌聲太早，將歌聲延後。填入總校正量，不是累加；配樂與和音不移動。初始值沿用本輪錄音校正值；舊錄音沿用當時保存的時間補償。

        包含這筆原始錄音、乾淨歌聲、時間位置與評分基準；只下載到本機，供檢查對齊問題。

        選擇已保存的錄音後，可調整基準與難度重新評分。

        錄音設定 錄音內容 · 歌聲延時 · 音量平衡

        新錄音使用同步無損 WAV，保留原始歌聲供後製，檔案會比壓縮錄音大；每輪最多 30 分鐘。

        按「從頭開始唱」，影片開始播放時同步錄音；停止收音、結束並結算或影片播完時保存。暫停／緩衝時暫停錄音。依已載入版本自動選軌：兩軌版本加入伴奏；四軌版本加入伴奏＋和音，不加入原唱主唱或全部人聲。超過音軌長度後只錄歌唱者。請戴耳機，避免原唱從喇叭漏入麥克風。

        預設＋200 ms：停止錄音後，成品中的歌聲往前移 200 ms，配樂與和音不移動。填入總校正量，不會累加。原始歌聲保留供後處理；即時評分仍使用上方時間補償設定。

        錄音音量平衡

        未勾選：自動平衡歌唱者與配樂／和音。勾選後使用你設定的音量，系統只做小幅修正。

        自動平衡 · 平滑調整音量，低音量或未偵測到穩定歌聲時不自動增強麥克風。只影響錄音，不影響評分；每輪開始前設定。

        暫停與緩衝不計分。漏唱與跳過的段落會降低分數；「整首歌曲」模式也會計入提前結束的剩餘段落。可在中途按「結束並結算」，或等影片播完自動結算。進拍分數依旋律起音估計，不是專業聲樂評鑑。
