收音設定 收音方式 · 麥克風選擇

本機相容模式由這台電腦的 Python 收音，需要啟動本機工具並允許 Python 麥克風權限。聲音只送回本機瀏覽器；仍依下方錄音選項決定是否保存。切換收音方式後請重新測試延遲。

第一次允許收音後可選裝置。建議先用有線耳機或 USB 麥克風測試。

先確認本機工具

只在你的電腦處理音訊

尚未檢查。第一次使用請安裝；已安裝則啟動本機工具。

GitHub Pages 只提供網頁。下載、分離與後續評分在你的電腦執行。

安裝／啟動說明（Windows）
  1. 下載本機工具包，解壓縮到固定資料夾。第一次需先備妥 Python 3.12、Node.js 22 以上 與 FFmpeg。
  2. 在該資料夾開啟 PowerShell，第一次執行：powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-local.ps1工具與模型會安裝在本機，不會上傳你的音訊。
  3. 每次重開機後啟動：powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1回到此頁點「檢查本機工具」。如果瀏覽器詢問本機網路存取，請允許。

重開機不會移除安裝。只有關閉本機工具、重開機後未啟動，或連線權限被拒絕時，需要重新連線。Windows 重設／重灌後可能需要重建。

      調整音量與延時，不必重唱

      請選擇一筆錄音。

      連接本機錄音目錄中…

      100% 沿用錄音時的音量平衡；往左降低、往右提高，0% 靜音。配樂與和音一起調整；只錄歌唱者的錄音無配樂可調。按「重新合成」後才會套用，再播放成品試聽；成品會保留目前設定，可繼續後製，每次都從原始歌聲重新計算。

      正值：歌聲晚到，將歌聲提前；負值：歌聲太早，將歌聲延後。填入總校正量，不是累加；配樂與和音不移動。初始值沿用本輪錄音校正值；舊錄音沿用當時保存的時間補償。

      音色效果：輕度稍微柔和，中度明顯降低尖亮感，強烈做出厚柔、較暗的音色；不是修復原音或消除呼吸聲。只處理歌唱者，配樂與和音不套用。選好後按「重新合成」另存，原錄音及評分不變；強烈會犧牲一些明亮感與咬字清晰度。比較強度時保持相同音量與延時；選取成品可再調整，柔化不會重複疊加。

      只處理歌唱者

      四項預設關閉或中性。按「重新合成」另存後試聽；每次從原始歌聲重算，效果不會疊加。配樂／和音不套用這些效果。

      局部音量

      依這筆錄音播放器的秒數設定開始與結束，不是 YouTube 時間。只調指定區段；100% 不變、0% 靜音，區段不可重疊。變更延時後請重新核對區段位置。殘響會自然延伸到區段外。

      EQ 音色

      0 dB 不變；往左減少、往右增加。先從 ±2～3 dB 比較。

      0% 關閉；可先試 5～10%。開啟後保留 0.8 秒尾音。

      重新合成會另存一筆，並保存獨立的原始歌聲與後製資料，可再次編輯或轉 MP3；原錄音保留。配樂／和音需歌曲庫中的同版本音軌。舊成品或單獨匯出的 WAV／MP3 若沒有原始歌聲及時間資料，無法直接分軌後製。選「不保存錄音」時不保留後處理資料。

      所有演唱錄音

      停止錄音後自動保存於歌曲庫下的「錄音」目錄；Chrome 與 Edge 連到同一本機工具即可共用。既有瀏覽器錄音會自動搬存，成功確認後才清除舊副本；未搬存成功仍保留在瀏覽器。直接按 YouTube 播放只評分；要錄音請按「從頭開始唱」。
